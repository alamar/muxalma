Этот модуль содержит демонстрационную реализацию транспорта на сериализации поверх TCP-сокета, обнаруживаемого внутри локальной сети посредством mDNS.

### Запуск

Выходная часть прокси запускается классом [`pvt/muxalma/mdns/MDnsMale.kt`](src/main/kotlin/pvt/muxalma/mdns/MDnsMale.kt) и может общаться с несколькими "мамами", запуская отдельного выделенного "папу" для каждой из них, реализуя безгаремный разделяемый режим.

Входная часть прокси ("мама") находится в файле [`pvt/muxalma/mdns/MDnsFemale.kt`](src/main/kotlin/pvt/muxalma/mdns/MDnsFemale.kt). При запуске она ищет "папу" через mDNS, а найдя, соединяется с ним и запускает HTTP-прокси на порту `18080`.
