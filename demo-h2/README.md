Этот модуль содержит демонстрационную реализацию транспорта на основе разделяемой базы данных H2 SQL.

### Запуск

Входная часть прокси ("наложница") запускается классом `pvt.muxalma.h2.H2ConcubineMain`, ожидая номер порта в параметре командной строки и запускает HTTP-прокси на этом порту.

Выходная часть прокси ("принц") запускается классом `pvt.muxalma.h2.H2PrinceMain` и может обслуживать несколько "наложниц" независимо, разделяя их по UUID клиента.
